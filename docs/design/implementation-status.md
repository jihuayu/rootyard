默认仓库读权限支持 owner 及已授权协作者/团队（`read` 及以上角色），非成员访问私有仓库统一返回 `404 Not Found`。隐藏 refs、不可达对象或 sparse checkout 不建立细粒度保密边界。Kafka 的已有适配器用于受控本地 broker，不能当作生产远程 TLS/SASL 集群配置。服务的其余安全和部署前提见 [运行手册](../operations.md)。

CI 的 source-retention receipt 与 mirror-readiness receipt 是两种独立证据，由可信控制者核对。owner-wide token 不能交给不可信 runner；基线已增加绑定仓库、目标 OID、job、generation、镜像 audience 与绝对到期时间的作业凭证，一次性交付，最长一小时，并支持单调 cancel/revoke。作业读取使用只含目标可达闭包的独立视图，仍允许读取目标的完整祖先历史。每次请求及慢准备完成后再次授权；已准入的长传输不会被即时中止。已实现租约协同的显式 source pin 释放、PR 同步自动创建 CI source pin（`on_pull_synchronized`）、磁盘高低水位与 LRU 安全淘汰（`mirror-evict` / `mirror-prune`）、并发同步限流与 `mirror-status` / `/metrics` 观测；更完整的自动回源与跨集群 runner 调度仍是 [第 11 章](11-ci-read-mirrors.md) 的目标。Schema `030`（23 张公共表）/ Schema `060`（34 张公共表）/ backup format 5 恢复会撤销既有作业凭证，详见 [实现契约](../ci-mirror.md#bounded-job-checkout-credentials)。

## 计划与待验证事项

- 跨公有云多区域对象存储生产级加密/KMS 与大规模在线后台自动 Repack 调度。
- 跨数据中心 Raft/Patroni PG 自动主备切换与物理流复制灾备 RPO/RTO 实测。
- Workspace 内核态 FUSE/overlayfs 透明挂载与全写者内核级屏障。
- 完整跨集群 CI 作业调度与受控镜像自动回源。
- 在指定硬件、真实对象存储和工作负载上的规模/成本测试；原文容量数字和性能目标须实测。

这些能力的依赖和发布出口见 [分期路线](08-roadmap.md)。已有切片可以并行推进，不能以“第几期已开始”代替整期验收完成。
